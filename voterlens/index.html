How VoterLens Builds Your Dossier

VoterLens doesn't guess. It gathers live data first, then uses AI to reason over it. Every number in your dossier traces back to a named source.

📡 Data Layer

Wikidata SPARQL → live party list for your country (ideology, leader, spectrum, seats). Wikipedia REST API → party history, known scandals. World Bank API (no key, free) → GDP, unemployment, inflation, health spend, debt, GINI, CO₂, poverty rate. WHO GHO API → Universal Health Coverage score. All fetched fresh on every analysis.

🧠 Reasoning Layer

The AI receives all fetched data plus a structured prompt that forces it to: (1) cross-check every promise against real economic constraints, (2) flag any promise that is mathematically impossible given actual debt/revenue figures, (3) identify historical parallels to past policies, (4) detect rhetorical shifts from policy to identity/cultural language, (5) estimate wallet impact for poor and middle-class households separately.

📋 The Dossier

Output includes: Executive Summary · Accountability Pulse (4 gauges) · Veil-Remover Table (slogan → blueprint → hidden price) · History Mirror (parallels to past regimes/policies) · Promise Tracker · Personal Wallet Impact · Source Vault.
